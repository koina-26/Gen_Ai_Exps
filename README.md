# Gen_Ai_Exps
A hands-on exploration of generative AI, covering autoencoders, GANs, VAEs, diffusion models, and transformer-based text generation. This repository demonstrates building, training, and evaluating models across image, text, and multimodal tasks, along with ethical analysis of generated outputs.

🚀 Generative AI Experiments Collection

1️⃣ Autoencoder (AE)

Encode images into compact latent representations 🧠

Reconstruct input data using decoder 🔄

Train on MNIST for image compression & reconstruction


2️⃣ Generative Adversarial Network (GAN)

Generator creates synthetic images 🎨

Discriminator distinguishes real vs fake ⚖️

Train adversarially on MNIST digits


3️⃣ Conditional GAN (cGAN)

Generate images based on class labels 🔢

Control output (e.g., generate specific digits)

Incorporate label conditioning in both networks


4️⃣ Text Generation (GPT-2)

Use pretrained transformer models 🤖

Generate text from prompts ✍️

Experiment with sampling strategies (temperature, top-k)


5️⃣ Fine-Tuning GPT Models

Train GPT-2 / GPT-Neo on custom datasets 📚

Adapt model for domain-specific text generation

Applications: reviews, stories, chat-style text


6️⃣ Variational Autoencoder (VAE)

Learn probabilistic latent space 📊

Generate new data samples from distributions

Visualize and explore latent space structure


7️⃣ Image-to-Image Translation (Pix2Pix / CycleGAN)

Convert images from one domain to another 🖼️➡️🖼️

Pix2Pix → paired datasets

CycleGAN → unpaired datasets


8️⃣ Diffusion Models

Generate high-quality images from noise 🌌

Use pretrained models (e.g., Stable Diffusion)

Focus on prompt-based image generation


9️⃣ Multimodal AI (Image Captioning)

Generate captions from images 🖼️➡️📝

Use models like CLIP / BLIP

Learn vision-language relationships


🔟 Ethical Evaluation

Analyze outputs for bias & fairness ⚖️

Detect toxicity and harmful content 🚫

Apply responsible AI practices & moderation tools


✨ Tech Stack: PyTorch | TensorFlow | Hugging Face
